# کشتی‌یار — نسخه اولیه برای Netlify

این بسته یک صفحه معرفی واکنش‌گرا برای شروع انتشار است؛ **سامانه عملیاتی مسابقات نیست** و هنوز پایگاه داده یا ورود کاربران ندارد.

## انتشار از GitHub در Netlify
1. فایل‌های این بسته را در ریشه مخزن `koshtiyar-langarud` بارگذاری کنید.
2. در Netlify گزینه `Add new project` → `Import an existing project` → `GitHub` را انتخاب کنید.
3. مخزن `RaminRakhshani/koshtiyar-langarud` و شاخه `main` را انتخاب کنید.
4. برای این نسخه HTML/CSS ساده، Build command را خالی بگذارید و Publish directory را `.` قرار دهید.
5. روی Deploy بزنید.

## هشدار
این نسخه صرفاً صفحه شروع است. اطلاعات واقعی ورزشکاران را وارد نکنید. اتصال امن Supabase، سیاست‌های دسترسی، احراز هویت، ثبت نتایج و آزمون‌ها باید جداگانه انجام شود.
